# 特殊变量

获取执行脚本时传入的若干参数，编辑 `demo.sh` 文件内容如下。

```shell
#!/bin/bash
echo "Script Name: ${0}"
echo "1st Parameter ${1}"
echo "2st Parameter ${2}"
```

统计执行脚本时传入的参数总数，编辑 `demo.sh` 文件内容如下。

```shell
#!/bin/bash
echo "Parameter Count: $#"
```

将所有传入的参数合并为完整字符串，编辑 `demo.sh` 文件内容如下。

```shell
#!/bin/bash
echo "Parameter String: $*"
echo "Parameter String: $@"
```

执行下面的命令，获取上一条命令执行后的返回状态码， 0 代表执行成功，非 0 代表执行失败。

```
ls /etc/passwd; echo $?
```
