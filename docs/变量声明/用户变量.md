# 用户变量

执行下面的命令，定义指定的变量。

```
num=233
```

执行下面的命令，访问指定的变量。

```
echo $num
```

执行下面的命令，解析双引号内的变量。

```
echo "num: ${num}"
```

执行下面的命令，删除指定的变量。

```
unset num
```

执行下面的命令，定义只读变量，一旦赋值则不能修改或删除。

```
readonly str='Hello World!'
```

执行下面的命令，将变量导出为环境变量，使子 Shell 能够继承使用该变量。注意，导出只能向下传递。

```
export num=233; bash -c 'echo $num'
```
