# 条件判断

判断指定的两个整数是否相等，编辑 `demo.sh` 文件内容如下。

```bash
#!/bin/bash
num1=233
num2=666
if [ ${num1} -eq ${num2} ]
then
    echo 'num1 = num2'
else
    echo 'num1 != num2'
fi
```

判断指定的整数是否大于另一个整数，编辑 `demo.sh` 文件内容如下。

```bash
#!/bin/bash
num1=233
num2=666
if [ ${num1} -gt ${num2} ]
then
    echo 'num1 > num2'
else
    echo 'num1 <= num2'
fi
```

也可以通过下面的方式来进行浮点数比较，编辑 `demo.sh` 文件内容如下。

```bash
#!/bin/bash
num1=1.23
num2=4.56
result=$(echo "${num1} <= ${num2}" | bc)
if [ ${result} -eq 1 ]
then
    echo 'num1 <= num2'
else
    echo 'num1 > num2'
fi
```

判断指定的文件或目录是否存在，编辑 `demo.sh` 文件内容如下。

```bash
#!/bin/bash
file='/etc/passwd'
if [ -e "${file}" ]
then
    echo true
else
    echo false
fi
```

判断指定的文件是否存在，并且是否为文件类型，编辑 `demo.sh` 文件内容如下。
